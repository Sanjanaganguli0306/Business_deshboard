# Business_deshboard
An interactive, dark-themed Executive Business Analytics Dashboard built using Streamlit and Plotly. This production-ready web application aggregates retail and transaction data to track key performance metrics and regional sales insights.

## 🚀 Features
- **Dynamic Filtering:** Sort analytics instantly by region and product category via the interactive sidebar.
- **Key Performance Indicators (KPIs):** Real-time calculation of Total Revenue, Net Profit, Orders Fulfilled, and Average Profit Margins.
- **Advanced Visualizations:** - Weekly Revenue Performance Trends (Line Chart)
  - Revenue Share Breakdown (Donut/Pie Chart)
  - Product Category Sales Quantities (Bar Chart)
  - Transaction Profitability Analysis (Scatter Plot)

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Visualization:** Plotly Express
- **Data Manipulation:** Pandas, NumPy
- **Deployment:** Streamlit Cloud
